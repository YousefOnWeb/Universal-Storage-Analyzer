# Vision

Universal Storage Analyzer turns opaque storage footprints into transparent,
actionable insight: high-performance scanning, real-time visualization, and
mass remediation — 100% free and open-source, on Windows, macOS, and Linux.

Primary users: sysadmins/DevOps, power users/creators, compliance auditors.
North star: select any target (local today; network/cloud in later milestones)
and browse trustworthy, live size data without the UI ever freezing.
